# COOKOUT Aruba - Web Oficial (Tenant 8)

Sitio web oficial e informativo de **COOKOUT Aruba by Green Fish**, creado para la promoción del menú oficial y experiencia gastronómica del **Beach Tennis Aruba Open 2026** en Bushiri Beach.

## 🍔 Características

- **Diseño Inspirado en la Marca**: Tipografía varsity/collegiate, fondos dark slate charcoal, banners cream bone y acentos ámbar parrillero y turquesa caribeño inspirados en el menú oficial y en [@cookoutaruba](https://www.instagram.com/cookoutaruba/).
- **Catálogo Completo de 17 Platos Elaborados**:
  - *From The Grill*: Smash Burger, Choripán, Ribeye Steak Sandwich, Ribeye Steak & Fries, Half Grilled Chicken & Fries, Extra Fries.
  - *From The Griddle*: Mahi-Mahi Sandwich, BLT Chicken Wrap.
  - *Crispy Classics*: Loaded Fries (Cheddar & Bacon / Beef Chili & Sour Cream), Chicken Parmesan, Crispy Chicken Sandwich, Fish & Chips, Calamari.
  - *From The Salad Bar*: Grilled Bowl, Salmon Poke Bowl, Ceviche fresco del día.
- **Formato Informativo**: Sin carrito ni pasarela de pago obligatoria; pensado para consulta, exploración de ingredientes, fotos en alta resolución y contacto directo por WhatsApp e Instagram.
- **Staff & Family Menu Perk**: Banner y aviso especial para la comunidad del torneo, árbitros y organización.
- **Sincronización Dual**: Conexión en vivo con el backend de Food (`tenant_id=8`, `marca_id=7`) y catálogo estático offline de respaldo instantáneo.
- **SEO & Structured Data**: Marcado Schema.org con `Restaurant`, `Menu` y `SportsEvent`.

## 🚀 Desarrollo y Compilación

```bash
# Instalar dependencias
npm install

# Modo desarrollo (puerto 5179)
npm run dev

# Compilar para producción
npm run build

# Vista previa de build
npm run preview
```
